# «Ритм»

«Ритм» — учебный сайт-трекер привычек: каталог привычек с фильтром, страница привычки, вход и регистрация, импорт и экспорт отметок. На нём по шагам разбираются все шесть лабораторных работ курса: от вёрстки до PHP-приложения с базой данных и админкой.

Код каждой лабораторной лежит в своей папке и работает сам по себе:

| Папка | Лабораторная | Что внутри |
|---|---|---|
| [`LR1/`](LR1/) | ЛР 1 | Вёрстка всех страниц на HTML и Bootstrap, без серверной части |
| [`LR2/`](LR2/) | ЛР 2 | Главная на PHP: привычки и категории из MySQL, фильтр через GET-параметры |

## Как запустить

**ЛР 1** — откройте `LR1/index.html` в браузере.

**ЛР 2** нужен PHP 7.4+ с `pdo_mysql` и MariaDB/MySQL, например XAMPP:

1. Положите репозиторий так, чтобы папка `LR2` открывалась по адресу `http://localhost/LR2/`.
2. В phpMyAdmin создайте базу `rhythm` с кодировкой `utf8mb4_unicode_ci` и импортируйте в неё `LR2/core/db/install.sql`.
3. Если адрес сайта или доступ к базе другие, поправьте `LR2/core/config.php`.
